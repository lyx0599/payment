# Personal Money Map · 2026

一个用于复盘个人消费结构的静态记账看板。页面合并微信支付与支付宝流水，以实际消费净额为统一口径，回答一个简单的问题：钱，主要花到哪里了？

## 在线查看

[打开 2026 年度资金流向看板](https://lyx0599.github.io/payment/)

## 看板内容

- 年度总支出、月度趋势和消费大类占比
- 一级分类 → 二级分类 → 交易对手方逐级下钻
- 「旅行 / 日常 / 上班」场景标签与旅行地点标签筛选
- 旅行专项成本：按行程查看总成本、日均成本和费用构成
- 上班专项成本：按月份查看通勤、吃饭、咖啡等净成本
- 高额商户、完整流水明细及收入抵扣清单
- 支出和已确认收入抵扣共用同一份最终净流水，保证上下看板口径一致

## 数据口径

- 收入不单独展示，只用于抵扣对应支出。
- 场景与地点标签按逐笔流水保存；同一笔流水以最新修改为准。
- 旅行交通包括机票、火车、租车和打车。
- 金额计算精确到分，页面汇总卡片按元取整显示。
- 当前数据范围：2026 年 1 月 1 日至 2026 年 8 月 18 日。

## 技术说明

项目是单文件静态页面，无服务端和数据库。页面数据、样式与交互均包含在 [`index.html`](./index.html) 中，并通过 GitHub Actions 自动发布到 GitHub Pages。

推送到 `main` 后，[Pages 工作流](./.github/workflows/deploy-pages.yml) 会自动重新部署：

```bash
cp analysis.html index.html
git add -- index.html
git commit -m "Update payment dashboard"
git push origin HEAD:main
```
